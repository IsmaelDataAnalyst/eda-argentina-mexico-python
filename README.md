# 📊 Análisis Comparativo: Argentina vs México (2000–2026)

Proyecto desarrollado con Python para aplicar el flujo completo de un Análisis Exploratorio de Datos (EDA) comparando indicadores económicos entre Argentina y México durante el periodo 2000–2026.

## 📖 Descripción

Este proyecto presenta un Análisis Exploratorio de Datos (EDA) utilizando Python para comparar el comportamiento económico de Argentina y México entre los años 2000 y 2026.

## 🎯 Objetivo

Aplicar el flujo completo de un Análisis Exploratorio de Datos (EDA) mediante Python, utilizando las librerías Pandas, Matplotlib y Seaborn para obtener información relevante a partir de un conjunto de datos económicos.

## 🛠️ Tecnologías utilizadas

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- JSON

## 📂 Contenido del proyecto

- Carga del dataset
- Exploración de datos
- Calidad de datos
- Estadísticas descriptivas
- Análisis univariado
- Análisis bivariado
- Análisis comparativo
- Dashboard ejecutivo
- Conclusiones
